Работай только в этом репозитории. Подробности — `README.md` и `NAS_BACKUP_PROTOCOL.md`.

## Git

- Перед началом работы: `git pull --ff-only`.
- После завершённых изменений сразу коммитить и пушить в `main` (`git pull --rebase` → `git push origin main`), не спрашивая, — так облачные и локальные сессии видят один и тот же код. Ветки не создавать, force-push нельзя.
- Не коммитить секреты (`.env*`, `.local/`, ключи, пароли). Чужие или несвязанные незакоммиченные изменения не включать в коммит — сказать о них пользователю.
